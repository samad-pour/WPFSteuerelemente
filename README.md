# WPFSteuerelemente

Ein Visual-Studio-Projekt zur Einführung in die Verwendung verschiedener Steuerelemente innerhalb einer WPF-Anwendung.

## Beschreibung

Das Projekt **WPFSteuerelemente** beschäftigt sich mit den Grundlagen der Benutzeroberflächenentwicklung mit Windows Presentation Foundation (WPF). Im Mittelpunkt stehen die Verwendung, Gestaltung und Interaktion verschiedener Steuerelemente innerhalb einer grafischen Anwendung.

## Funktionen

- Darstellung verschiedener WPF-Steuerelemente
- Verwendung von Schaltflächen und Eingabefeldern
- Integration von Auswahl- und Bedienelementen
- Verarbeitung von Benutzerinteraktionen
- Gestaltung grafischer Benutzeroberflächen mit XAML
- Grundlagen der ereignisgesteuerten Programmierung

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Windows Presentation Foundation (WPF)
- XAML

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WPFSteuerelemente.git
   ```

2. Die Datei `WPFSteuerelemente.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
